# Risk-Management---Group-1

Team GitHub Protocol

Start with the latest version. Switch to main and run git pull before starting new work.

Create a branch for your changes. Use a descriptive name, such as update-riskiness-index. Do not commit or push directly to main.

Commit and push your branch. Use commit messages that clearly describe what you changed.

Create a pull request (PR) into main. Include a short description of your changes.

Ask another team member to review your PR. Address their feedback and obtain approval from at least one other team member before merging.

Merge after approval. Delete the merged branch and pull the updated main before starting your next task.
